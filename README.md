# af3io-testdata

- `alphafold3_examples` input JSONs from
`examples/` at [google-deepmind/alphafold3](https://github.com/google-deepmind/alphafold3) with predictions, compressed with `gzip`
- `mgen_pools_5k_top3/` three pooled inputs (~5k tokens each),
compressed with `zstd`,
downloaded from [`pools_5k.tar`](https://zenodo.org/records/16920556)
